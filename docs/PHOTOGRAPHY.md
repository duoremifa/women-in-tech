# 摄影 & 视觉素材规范 · wotech.space

站点的调性是**顶奢克制 + 杭州生活锚点 + 纸感肌理**（参考法云安缦 / Amanfayun）。所有照片要坐到这套调性之下，而不是与之争锋。这篇是你后续拍摄、选图、后期的准绳。

---

## 一、调色目标（Color Grading）

**一句话**：暖纸底、低饱和、柔对比、金光、墨影。照片像印在棉纸上，不是手机屏幕上。

### 色板锚点（与站点 token 同源）

| 角色 | hex | 用法 |
|---|---|---|
| 暖纸底 / cream | `#fdfcf9` / `#f7f5f0` | 高光、背景留白 |
| 亚麻金 / gold-dust | `#d8cdb0` | 暖光、金属点缀、金线 |
| 墨 / ink | `#26221c` | 阴影、深色块（不用纯黑） |
| 暖灰 / warm grey | `#aba49a` / `#8a8478` | 中间调、次要文字 |
| 深夜炭 / charcoal | `#1e1d1b` | 深色模式背景 |

**禁止色**：纯黑 `#000`、纯白 `#fff`、霓虹饱和色、冷蓝冷绿。所有色都带暖调（+R，-B）。

### 后期参数（Lightroom / Snapseed / VSCD 通用）

落地到站点时，图片会被 CSS 套一层 `--img-filter: saturate(0.88) contrast(0.98) brightness(1.02)`。所以**前期拍得比想要的稍微鲜艳一点点**，上线后会被这层 filter 压回纸感。但不要依赖 filter 救烂片——前期就该接近目标。

| 参数 | 目标值 | 说明 |
|---|---|---|
| 饱和度 Saturation | −10 到 −20 | 降，但不灰。植物绿、品牌色保留一点 |
| 对比度 Contrast | −5 到 −10 | 柔，不要硬。阴影保留细节 |
| 高光 Highlights | −20 到 −40 | 压白，不要溢出 |
| 阴影 Shadows | +10 到 +20 | 提一点，保留暗部细节 |
| 色温 White Balance | +5 到 +15（暖） | 偏暖黄，不要冷 |
| 色调 Tone | 略偏黄绿（+Magenta 一点点反向来压绿） | 杭州植物多，绿色易过饱和 |
| 颗粒 Grain | +5 到 +10（轻） | 模拟胶片纸感，但克制 |
| 清晰度 Clarity | −5 到 0 | 不要锐化过度，柔一点 |

### 暗部与高光

- **暗部不要死黑**——目标 `#1e1d1b` 而非 `#000`。深色模式照片尤其要保证暗部有暖灰层次。
- **高光不要溢出**——白墙白纸留一点纹理（`#fdfcf9` 不是 `#ffffff`）。

## 二、拍摄准则（Shooting）

### 光线

- **只用自然光**。窗口侧光、清晨/傍晚黄金时段、阴天柔光最好。
- **禁闪光**（机顶闪、手机补光灯都算）。闪光破坏纸感。
- 室内：靠窗拍，让光从一侧来；背光面用反光板（白纸/白板）补，不要补成平光。
- 室外：黄金时段（日出后 1h、日落前 1h）。正午硬光避开，除非在阴影里拍。

### 构图

- **负空间优先**。主体居中或偏左下，四周留白。参考法云安缦官网的留白比例。
- **4:3 或 3:2**。竖构图用于人/店面，横构图用于场景/路线。
- **不要塞满画面**。一张图只讲一件事——一家店、一双手、一段路、一个器物。
- **平视或微俯**，不要仰拍（仰拍像商业广告）。手作细节用俯拍。
- **前景虚化**偶尔可用，制造层次，但不要每张都虚。

### 主体（杭州生活田野）

按 `/writing` 田野手记方向：

1. **小店**：开了十年的咖啡店、酒铺、手作店。拍店面门头、吧台细节、店主的手、店里的物件。
2. **徒步/散步线路**：玉皇山台阶、西湖群山、巷子线。拍路本身（石板、树影、台阶），不要只拍远景。
3. **有特色的地方**：天目里、小河直街、某条巷子深处。拍让人停留的那个细节。
4. **人**：以个体之名在这座城市做事的女性。拍她们在工作中的状态（手、侧脸、背影、店里忙碌的瞬间），不要摆拍笑脸。

### 人物

- **不放 Dai Min 肖像**（作者隐于作品，by Dai Min 只在 footer）。
- 受访者肖像由本人提供或经本人同意拍摄。可以是真名或化名（受访者定）。
- 拍人：自然状态 > 摆拍。手部、侧影、工作瞬间比正脸更有质感。
- 不笑也可以。顶奢人像常常是不笑的、安静的。

## 三、禁拍清单（Don'ts）

- ❌ 过饱和 / HDR / 高对比硬光
- ❌ 手机滤镜重涂（VSCO A6 之类一键预设不要直接用，要手动调到上面参数）
- ❌ 仰拍 / 广角变形 / 鱼眼
- ❌ 摆拍笑脸 / 商业模特感
- ❌ 文字水印 / 时间戳 logo（站点不放水印）
- ❌ Dai Min 本人肖像做主图
- ❌ 与杭州无关的素材图库照片（要真实，不要 stock）
- ❌ 竖屏短视频截图、带 UI 的截图

## 四、交付规格

| 项 | 规格 |
|---|---|
| 宽度 | 1200–1600px（横图）/ 900–1200px（竖图） |
| 比例 | 4:3（封面/场景）/ 3:2（人/器物）/ 1:1（播客封面） |
| 格式 | jpg（照片）/ webp（更优）/ png（需透明时） |
| 色彩空间 | sRGB（web 标准） |
| 文件大小 | 单张 < 400KB（用 Squoosh / TinyPNG 压） |
| 命名 | 小写连字符，如 `linda-wine-shop.jpg`、`yuhuang-trail-01.jpg` |

### 放哪

- 播客封面 → `public/podcast/ep-01.png` → frontmatter `cover: /podcast/ep-01.png`
- 手记封面 → `public/writing/linda.jpg` → `cover: /writing/linda.jpg`
- 作品截图 → `public/works/sound-field.jpg` → works.ts `cover: /works/sound-field.jpg`
- 通用图 → `public/images/<slug>.jpg`

详见 `docs/CONTENT_GUIDE.md`。

## 五、站点的图片处理（CSS）

站点会自动给封面图套：

- `aspect-ratio: 4/3` + `object-fit: cover`（统一比例，不破坏 8px 网格）
- `filter: saturate(0.88) contrast(0.98) brightness(1.02)`（纸感调色，让照片坐到肌理之下）

所以你交付的照片**会被站点再压一点饱和/对比**。前期就调到位的话，上线后会很接近你看到的——不会变样。

深色模式下纸感纹理换浅噪点（screen 叠加），照片不变色，只是底下肌理换。

## 六、参考视觉（不是抄，是校准调性）

- **法云安缦 Amanfayun 官网**：暖纸、低饱和、负空间、材质特写。
- **Aman 全球各分号官网**：构图克制、人像安静、光影自然。
- **Kinfolk 早期杂志**：暖灰调、手作细节、生活感。
- **Cereal Magazine**：极简留白、建筑/空间/手作。

校准时问自己：这张图放进法云安缦官网会不会违和？会，就重调或重拍。

## 七、一张图的检验清单

交付前自问：

- [ ] 暖调（不是冷蓝）？
- [ ] 饱和降了（但不灰）？
- [ ] 高光没溢出、暗部没死黑？
- [ ] 有负空间、不塞满？
- [ ] 主体是一个（不是一堆）？
- [ ] 自然光、无闪光？
- [ ] 不是 Dai Min 肖像？
- [ ] 与杭州有关、真实、非 stock？
- [ ] < 400KB、sRGB、命名规范？

全过 → 交付。
